## Vilanera

Vilanera makes bags and backpacks for people who dress well and travel often, designed and made in Italy.

### Open data

**[Carry-on size by airline](https://github.com/vilanera/carry-on-size-by-airline)**: cabin bag and personal item limits by airline, as JSON and CSV. Every row links to the airline's own baggage page and carries the date we last checked it. Free to use under CC BY 4.0.

The same data powers our free [hand-luggage size checker](https://vilanera.com/pages/hand-luggage-checker), where you enter a bag's measurements and see which airlines it fits.
